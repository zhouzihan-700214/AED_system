# Today’s Issues View — v10.2

## Behaviour

- Adds a directly visible **All Issues / Today’s Issues** switch.
- Today’s Issues is based on the `Reported At` calendar date.
- Displays the current date and count of Issues reported today.
- Keeps Search, Month, Issue Type, Issue Status, Reported By, Assigned By,
  Assigned To, Started By, Resolution Submitted By, Verified / Closed By and
  Custom Date Filter available in the Today view.
- Filter option lists are generated from the active scope, so Today’s Issues does
  not show irrelevant people or Issue types from older records.
- Reset Filters keeps the active All/Today scope.
- Direct navigation to a specific Issue switches to All Issues so older records
  remain reachable.
- Sorting remains `Reported At` newest first in both views.
