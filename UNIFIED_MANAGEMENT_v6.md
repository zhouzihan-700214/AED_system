# Unified AED Management v6

## Final interaction model

`AED Management` is the only visible asset-control entry. It keeps the original management KPIs, attention queue and PM progress, then provides one directory workspace:

- one keyword search;
- one linked-filter set;
- one filtered AED result set;
- `Browse Units` for row-click profile navigation;
- `Direct Edit` for the complete Master Table workflow.

Clicking a Browse Units row stores its `Serial Number` and opens the electronic profile. Returning to the list preserves the search and linked filters.

## Preserved Master Table capabilities

- reviewed multi-cell editing;
- before/after comparison;
- OneDrive Excel conflict protection;
- full-details editor;
- Add AED and Deactivate AED;
- audit, transaction, conflict and Excel-write histories.

The old `AED Master Table` and `AED Master Data` routes remain registered for old links and session values, but immediately redirect to `AED Management → Direct Edit`.

## Optimized Unit Profile

The profile includes:

- summary header and unit status;
- PM and service snapshot;
- issue summary;
- grouped full master information;
- recent service activity;
- Overview, Edit Details, Service History, Add Service and Issues;
- shortcuts to PM Checklist, Report Issue, Service Records, AED Map and Table Edit.

All field round-trip, PM, service-record, Issue and OneDrive behavior from v5 remains in place.
